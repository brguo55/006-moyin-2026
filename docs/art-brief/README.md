# 美术需求（像素风 · 给老师）

画面里现在只有 **rabbit** 是老师画的；房子、家具、兔耳小鸟、小图标都还是用代码临时画的。
这份说明把房子里的东西**一件一件列出来**（名字、位置、大小、现在的样子），老师照着重画，画好放进来就能直接换上，不用改别的。
下面写的位置和大小是为了对得上；**风格、细节、配色都以老师为准**（30% 原则），我写的只是方便理解大概要什么。

方向：rabbit 坐在一把悬浮的金椅子上（像诸葛亮的四轮车，但是飘着），住在人造小行星上一间**国风 + 星海**的木屋里，要**温馨**，不要冷冰冰的霓虹赛博。概念图在 [`concepts/`](concepts/README.md)。

---

## 一、整体风格

- **像素画**：不要抗锯齿、不要模糊、不要缩放或旋转出来的「半个像素」。半透明只用在灯光、玻璃反光和阴影上。
- **按 1 倍画**：1 个像素就是游戏里的 1 格，不要放大后再交。游戏会按整数倍放大（Mac 上大约 4 倍）。
- **角色和房子分得开**：rabbit 的描边深、对比强；房子的描边用深棕（参考 `#3d2c2a`），颜色比角色淡、灰一点，让角色跳出来。
- **氛围**：暖暖的中式木屋（红漆柱、回纹、灯笼、书柜、挂轴），窗外是穹顶里的庭院（白墙黛瓦、竹子，下着人工雨），再往外是星海。
- **主题色**：画面底部有 7 个主题色，会改变**墙纸和地毯**的颜色。墙纸、地毯请各画成单独一层，用接近白色的浅灰画出明暗，程序会上色；其余部分只画一套。

## 五、摆设清单（每样单独一张，可以一件一件换）

- 每样画成**一张透明 PNG**，**大小和下表一样**（宽 × 高），放的位置是表里的 (x, y)（左上角，1 倍像素）。
- 文件名用表里的名字，比如 `computer.png`、`e_clock.png`。现在的样子在 `props/` 里同名的图。
- 画好放进 `assets/house/`，告诉我名字，我把它加进代码里的 `PROP_ART`，游戏就改用老师的图。
- 想改大小或者位置也可以，告诉我新的数字，我来改代码。**顶面能站的东西**，顶面的高度要和第七节对上（或者告诉我新的高度）。
- **窗户**：玻璃那块要**留透明**，形状、大小和现在一样（程序先把玻璃挖空再贴图，窗外的景才透得出来）。
- **会动的部分不用画进去**，程序会画在图上面（第六节）；那块地方留出来，比如电子钟的屏留深色、番茄钟挂轴的纸留空白。

以后再约新的动作，**和以前的 GIF 保持一样就能直接用**：
- **画布一样大**：1120 × 832（也就是 1 倍的 280 × 208，放大 4 倍导出）；
- **椅子放在一样的位置**：程序从每一帧里裁出 x 100–180、y 36–148（1 倍）这一块，椅子底的中点对着同一个点，换帧时人才不会抖；
- **背景用一样的两种灰蓝色**（程序会把背景去掉）；
- 每帧多长时间就照 GIF 里设的，程序读得出来；
- **文件名照以前的规矩**，比如 `62_xxx_rabbit`；只要朝右的就不用写 left / right。

兔耳小鸟现在是 14 × 13、两帧的临时图（`assets` 里没有，程序画的）。它可以左右对称，约一套就够，程序会翻转：飞着跟在 rabbit 身边（循环）、被点时跳一下，rabbit 睡着时它也可以停下来睡。
