# 新方向概念图：国风 + 星海（温馨）

主角换成 **rabbit**：坐在一把悬浮的金色椅子上（像诸葛亮的四轮车，但是飘着，底下没有喷火），一半是机械身体。世界观参考《星海镖师》：人类住在人造小行星上，古风和星际科技混在一起。画面要**温馨**，不要冷冰冰的霓虹赛博。

| 文件 | 内容 |
|---|---|
| `cozy_room_1x.png` | 一屏的概念图，**1 倍像素**（448 × 252），不带角色 |
| `cozy_room_3x.png` | 同一张放大 3 倍，方便看 |
| `cozy_room.gif` | 动态版（2 倍）：下雨、星星闪、镖船飞过、灯笼摇、浑天仪转、茶冒热气 |

> 这些是用代码画的占位概念图，用来定方向、给画师当参考，不是最终美术。

## 画面里有什么

- **屋里**：中式木构书房。
  - 暖色墙、红漆柱、天花板木梁、两盏灯笼；
  - 博古架上有书、青花瓷瓶、盆景、卷轴，还有一个铜浑天仪；
  - 护墙板用回纹，和 rabbit 椅子侧面的花纹呼应；
  - 茶桌和茶具；
  - 右边的挂轴就是番茄钟，倒计时数字由程序画。
- **月洞窗外**：
  - 近处：人造小行星上的穹顶庭院，白墙黛瓦、竹子、小灯，下着人工雨（保留「听雨」）；
  - 远处：星海、带环的行星、小月亮、漂浮小岛上的楼阁、挂着红旗的镖船。
- **地面**：木地板微微反光；rabbit 悬浮在一张红色圆地毯上方，离地约 11 像素，底下有一圈淡淡的金光。

## 尺寸

- 像素比例和 rabbit 的原图一致：rabbit 加椅子约 38 × 55 像素。
- 一屏 448 × 252。这张概念图相当于现在地图里**窗户**那一屏（月洞窗、茶桌）。
- **整张地图照旧是 1800 × 500**（约 4 屏宽、2 层），平台坐标沿用 `../README.md` 里的表。
  - 门口、书架、窗户、电脑四块（电脑上面是阁楼），都按这个风格画。
